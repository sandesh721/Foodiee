# Foodiee
A full-stack food delivery application built with **Spring Boot**, **Hibernate**, **MySQL**, and **React**.

## 📌 Features

- User and Restaurant Owner registration
- Admin panel to approve/reject restaurant listings
- Menu and restaurant management
- Order placement and order history

## 🛠️ Tech Stack

**Frontend:** React  
**Backend:** Spring Boot, Hibernate, MySQL
**Database:** MySQL 



## Getting Started

### Backend
```bash
cd backend
./mvnw spring-boot:run
```
### Frontend
```bash
cd frontend
npm install
npm start
```
